# Isle WebXR

Isle is an immersive WebXR experience designed to support international students experiencing homesickness.

The experience allows users to revisit familiar memories through personal photos, videos, objects, notes, and voices in a spatial environment. Users can explore Heaven Isle, interact with memory objects, and move through portals to spaces such as Voice Isle.

This repository contains the WebXR prototype developed for the final exhibition of the MA User Experience Design project.

## Experience

- Explore personal memories in a spatial island environment
- Revisit photos, videos, objects, and notes
- Listen to familiar voices in Voice Isle
- Move between immersive spaces through portals
- Designed for browser-based XR and desktop viewing

## Status

This prototype is currently in development and will continue to be updated while keeping the same deployed URL.
